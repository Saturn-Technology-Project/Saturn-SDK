# Security policy

[中文](#安全政策)

The Saturn SDK follows Saturn's [security policy](https://github.com/Saturn-Technology-Project/Saturn-App/blob/main/SECURITY.md). Report a vulnerability privately to **[security@saturn-core.com](mailto:security@saturn-core.com)** or through this repository's **[Report a vulnerability](https://github.com/Saturn-Technology-Project/Saturn-SDK/security/advisories/new)**, never in a public issue. Only the latest version receives security fixes.

---

# 安全政策

[English](#security-policy)

Saturn SDK 遵循 Saturn 的[安全政策](https://github.com/Saturn-Technology-Project/Saturn-App/blob/main/SECURITY.md)。安全漏洞請私下寄至 **[security@saturn-core.com](mailto:security@saturn-core.com)**，或使用本 repository 的 **[Report a vulnerability](https://github.com/Saturn-Technology-Project/Saturn-SDK/security/advisories/new)**，不要以公開 issue 回報。只有最新版本會收到安全修補。
